Rien ne s'affiche ? Ici, la page est dans un cadre sécurisé qui peut bloquer la manette. Enregistre le fichier profil-gladiator.html que je t'ai envoyé sur ton PC, ouvre-le avec Chrome ou Edge, et refais le test.

Sans rien installer : Win + R → joy.cpl → choisis le VKB → Propriétés. Les numéros qui s'allument doivent correspondre à ceux de chaque carte ci-dessous (A2 = 3, A3 clic = 10, F1 = 27…).

Bon à savoir

    Installer le profil

    1. Ferme Star Citizen et copie ton fichier actuel pour le garder : C:\Program Files\Roberts Space Industries\StarCitizen\LIVE\user\client\0\Profiles\default\actionmaps.xml
    2. Mets layout_VKB_NXT_EVO_R_FR_exported.xml dans : C:\Program Files\Roberts Space Industries\StarCitizen\LIVE\user\client\0\Controls\Mappings\
    3. En jeu : Options → Keybindings → Advanced Controls Customization → Control Profiles → VKB_NXT_EVO_R_FR → importer le joystick.
    4. Sinon, dans la console : pp_rebindkeys layout_VKB_NXT_EVO_R_FR_exported

    Vérifie les numéros. Win + R → joy.cpl → Propriétés, puis appuie sur chaque bouton. A2 doit allumer le 3, le clic de A3 le 10, F1 le 27.

    Plusieurs joysticks branchés ? Si le jeu affiche js2_button1 quand tu appuies sur la gâchette, dis-le-moi et je refais le fichier pour js2.

    Logiciel VKB. Le profil suppose le réglage d'usine dans VKBDevCfg.

    Toutes les actions viennent du defaultProfile.xml de Star Citizen 4.10.2 (build 4.10.196.36804), via sc-mapper. Numérotation du NXT EVO R : BindSight, diagramme VKB (x4_vkb), forum VKB.
